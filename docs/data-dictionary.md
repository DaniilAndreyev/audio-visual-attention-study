# Data Dictionary

Output file: `data/participant_data.csv`

## Columns

- `participant_id`: sequential ID (`P001`, `P002`, ...)
- `date`: collection date in `YYYY-MM-DD` format
- `age`: age value provided by participant
- `gender`: slider rating index (`1`-`5`)
- `condition_order`: assigned order (`BLACK_FIRST` or `VIDEO_FIRST`)
- `score_black`: total correct responses for BLACK condition
- `score_video`: total correct responses for VIDEO condition

## Id generation

`participant_id` is generated by counting existing rows and assigning the next number.
